# Windows 本地视频制作

按用户选择的阶段处理目标目录。交付范围默认是本地文件。将客户主题、画幅、模板、时长和配音作为本单输入。

## 确认可用能力

- **已有引擎**。在指定工程中核对 `package.json`、`src/contracts.ts` 及存在的安装与渲染入口，再读对应引擎文档。原参考引擎的迁移与样片步骤见 [Windows 引擎手册](references/windows-engine.md)。
- **只有 Skill**。先做目录、Windows 运行时和引擎文件检查，交付缺项清单。可继续整理需求、脚本或工程骨架。把渲染验收标为「待引擎」，直到实际生成并探测 MP4。
- **使用智心 AI MCP**。按目标会话可见的工具和实测输出选适配路径。只有发布能力时，制作走本地引擎。参见 [智心 AI MCP 接入](references/zhixin-mcp.md)。

## 按阶段制作与验收

| 阶段 | 操作 | 验收证据 |
| --- | --- | --- |
| 环境 | 核对项目路径、Windows、Node.js 和本地渲染依赖。有兼容引擎时先验证无密钥样片。 | 环境与缺项清单。跑过样片时记录退出码、产物路径和媒体参数。 |
| 需求 | 按 [客户需求模板](templates/client-brief.md) 记录目标、风格、素材授权、禁用词、成片规格与交付方式。 | 本单需求、素材来源和待确认事项。 |
| 脚本 | 为每段填写完整上屏文字和对应口播，参考 [待审脚本](examples/script.example.json)。用模板槽位和假时标预检高风险版式，审稿通过后进入正式制作。 | 脚本契约、口播与字幕一致性、版式预检及审批结果。 |
| 配音 | 按本单授权使用用户配置的供应商。新音色先用两句试音，再按句生成和缓存。 | 可读的 WAV 和实际音频时长。按模板要求安排词级对齐。 |
| 渲染 | 用已验证的本地后端或本单授权的 MCP 制作工具，按任务编号分配工作目录。 | MP4 实测画幅、帧率、编码和时长，另抽看开头、中间与结尾并检查声音。 |
| 交付 | 给出本地成片及本单要求的附加产物。 | 文件路径、实测规格及尚待验证的环节。 |

参考引擎的默认交付规格为 **1920×1080、60/1 fps、16:9、H.264 MP4**。优先按本单确认的规格验收。长清单、型号和全屏文字单独检查换行、留屏与可读性。

## 迁移与授权

- 分发材料只取已授权的流程、代码、示例和素材。凭证、客户文件、浏览器资料、旧机器配置、生产状态和历史成片留在各自的运行环境。
- 按本单授权处理付费写稿、配音和素材上传。为本地验收选独立的测试副本及演示入口。生产排程和平台发布需要独立的发布流程。
- 写请求或付费调用的结果未知时，保留原任务编号与状态，先向供应商或任务查询接口对账。确认状态后再决定是否重做。
