# 定制视频需求单

每位客户、每条视频单独填一份。只填需求，不在这里填 API 密钥、账号密码、登录令牌或真实私有连接地址。

## 内容和风格

- **项目名 / 任务编号**：
- **用途 / 目标受众**：
- **主题与观众看完应记住的一句话**：
- **口播语言、语气、目标片长**：
- **字效与版式**：例如红白大字、逐词入场、结尾一屏清单；可附已授权的参考样片。
- **画幅 / 分辨率 / 帧率 / 格式**：未约定时先按 16:9、1920×1080、60/1 fps、H.264 MP4 验收。
- **必写信息与禁用词**：
- **来源与授权**：事实出处、商标/字体/图片/音乐可用范围、音色使用权限；不确定的内容标记待核实。
- **交付文件**：本地 MP4；是否另交文案、字幕或封面。

## 本单授权

- **稿件状态**：待审 / 已审（未确认前不进入正式制作）。
- **制作路线**：本地渲染 / 经确认可用的智心 AI MCP 制作。
- **付费模型或配音预算**：无，除非单独确认。
- **素材能否传到外部**：默认否；如允许，写清具体素材、目标服务和用途。
- **交付方式**：默认本地文件。此 Skill 不自动发布，也不自动创建排期。

首次演练请用演示数据。真实客户的素材、账号和订单状态留在该客户的受控工作目录，不放进 Skill 分发包。
