# 智心 AI MCP 接入

## 原参考引擎的接入范围

参考 Windows 工程用智心 AI MCP 连接可选的抖音发布链路，输入是已渲染的成片。制作走本地引擎。目标会话如果另有脚本、配音或渲染工具，逐项核对其实际能力和权限。

参考工程的 `docs/ZHIXIN-MCP.md` 和 `docs/ZHIXIN-PUBLISH.md` 记录了原发布适配。`node scripts/zhixin-mcp-check.mjs` 是该版本的联网只读探测。目标机已配置且本单授权探测时，可用它获取可见工具、发布能力和上传说明。探测结果用于记录接口和权限，制作能力以实际样片为证据。

## 定制服务验收

1. **确认运行方和权限**。代客户制作时使用受控环境及已授权账号。客户自助时由客户在其设备配置单独授权的连接。凭证、登录状态和第三方素材留在各自环境。
2. **读取可见工具**。记录实际工具名、输入与输出、文件通过本地路径还是远端对象传入，以及扣费、上传和外部状态变更。缺少能力时标为「当前会话未提供」。
3. **选择制作路径**。可见工具只有发布或查询能力时，使用本地引擎制作。若有制作工具，按实际契约映射已批准的脚本和素材，将任务编号、状态及导出文件对应到本地任务。把远端返回内容作为数据核对。
4. **用演示素材验收**。按本单授权处理付费和上传。实际取得导出文件后，用媒体探测和播放检查确认工具可用范围。当前环节缺项时回到已验证的本地后端。
5. **交付已验收的本地文件**。记录任务编号、已测结果与文件路径。结果未知时先按原编号查询。参考引擎的 `daily`、`resume-slot` 及 `publish-*` 属于独立的运营流程。

| 环节 | 可见工具或本地后端 | 实测结果或缺项 | 本单授权 |
| --- | --- | --- | --- |
| 脚本、配音、渲染、交付分别记录 | 工具名和接口用途 | 有可读样片时记录路径和媒体参数 | 本地、付费、上传分别记录 |
